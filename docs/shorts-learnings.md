## قرارات المستخدم (بالترتيب)
- القناة عالمية → السكريبت بالإنجليزي.
- أول 3 ثوانٍ يجب أن تكون "كارثية"، لا هادئة.
- لا مواضيع محلية (مصر/عين جالوت أُلغيت) → WW2 محدد ومعروف عالميًا مع حقيقة مخفية.
- الأسلوب: خريطة داكنة بخطوط، جغرافيا حقيقية، بدون صور أقمار صناعية، نصوص قليلة.
- السكريبت يُرسل ككتلة نص واحدة جاهزة للنسخ.
- النسخة الأولى من إنجما: "النصوص خارج الشاشة، الصور فوق النصوص، كل شيء عشوائي" → اعتمدنا نظام الأحزمة الثابت.
- ~~بدون SFX~~ → عُدّل: مؤثرات محسوبة في أماكنها المناسبة فقط.
- ألوان أرشيفية مقيدة وبدون توهج تمامًا.
- المؤثرات الصوتية كانت عالية → خفّضنا الكسب العام إلى 0.4 (src/lib/sfx.tsx).
- المستخدم أحب الخريطة (A) لكن بأسلوب ورقي → النسخة A-Paper. الدبابيس الصغيرة في C بدت مشوهة → لا دبابيس في الخريطة الورقية.
- نصنع نسخًا بأساليب مختلفة (A خريطة / B وثائقي / C ورقي) والمستخدم يختار ما يُنشر — نسجل أي أسلوب اختير ولماذا.
