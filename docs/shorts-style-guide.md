## 2. قواعد السكريبت (ثابتة)
1. **أول 3 ثوانٍ = صدمة/كسر خرافة.** صيغة: "[شيء يعرفه الجميع] … خطأ". لا تحية، لا "هل تعلم". أول كلمة قوية. (مثال: *Hollywood lied to you.*)
2. **الموضوع:** شيء محدد جدًا في WW2 يعرفه أغلب الناس بشكل، والحقيقة شيء آخر. عالمي، ليس محليًا.
3. **حلقة مفتوحة** في البداية تُغلق في النهاية؛ آخر جملة ترجع لفكرة أول جملة (loop).
4. **جمل قصيرة.** فقرة = لقطة. 60–75 ثانية (المراجع تنجح حتى 140ث إذا الصورة تتغير كل 2–3ث).
5. **مسار على الخريطة:** القصة يجب أن تتحرك بين أماكن (مدينة → مدينة) — كل محطة hook صغير.
6. **كل معلومة موثقة.** نتجنب الأرقام المختلف عليها، ونكتب ملاحظات تحقق في ملف السكريبت.
7. السكريبت يُسلَّم **ككتلة نص واحدة نظيفة** بدون أقواس أو توقيتات (للنسخ والتسجيل).

## 3. قواعد المونتاج (Remotion)
- **الأسلوب المعتمد:** خريطة داكنة بخطوط مضيئة (Vector) **بجغرافيا حقيقية**: سواحل Natural Earth 50m/10m، وحدود تاريخية حقيقية للسنة (مثل حدود 1938). ممنوع أي شكل مرسوم باليد.
- **رُفض:** النسخة الداكنة "الميتة" الأولى (أشكال تقريبية، نصوص كثيرة). **رُفض أيضًا:** صور الأقمار الصناعية (المستخدم فضّل الخطوط الداكنة).
- عناصر الحركة: رسم حدود الدولة تدريجيًا + تظليل مخطط، دبوس مكان + اسم + إحداثيات، مسارات متقطعة مضيئة برأس متحرك، أسهم عسكرية حمراء، نبضات إشارة، بطاقات صور أرشيفية مائلة بإطار أبيض وخط يربطها بالمكان.
- **نصوص الشاشة بالحد الأدنى:** أسماء الأماكن + كلمة/رقم واحد في اللحظات الكبرى (NOT، 1932، 5 WEEKS LATER). **لا كابشن كامل.**
- **الفريم الأول** يجب أن يحتوي العنصر الرئيسي ظاهرًا بالكامل (لا يبدأ فارغًا).
- الكاميرا تتحرك دائمًا (زووم بطيء حتى في الثبات)، والتنقل بين الأماكن بحركة سريعة + whoosh.
- لحظات الذروة: فلاش خفيف + اهتزاز بسيط (بدون صوت).
- **الصوت:** الراوي أولًا + مؤثرات لمسية محسوبة (ورق، دبوس، آلة كاتبة، دوّار، ختم) على لحظة التلامس، وضربة منخفضة فقط على الاكتشافات، وصمت مقصود عند أقوى لحظة. لا درون ولا whoosh متكرر. (`public/sfx` + `src/lib/sfx.tsx`)
- الألوان: اللوحة الأرشيفية المقيدة فقط (عاجي #E8DDC5، بيج #D5C4A1، فحمي #171817، حبر #292824، أحمر مؤكسد #A43B32، نحاسي #AD9163، رمادي #77736C). **بدون توهج نهائيًا.** الأحمر للحرب/الخطر/الاكتشاف فقط.

## 3.1 نظام التخطيط الثابت (إلزامي)
الشاشة 1080×1920 مقسمة لأحزمة، ولا عنصر يخرج عن حزامه:
| الحزام | y | المحتوى |
|---|---|---|
| واجهة يوتيوب العلوية | 0–220 | فارغ |
| حزام الكلمة | 250–400 | كلمة/رقم واحد فقط، يُصغَّر تلقائيًا ليبقى داخل العرض |
| حزام البطاقات | 440–960 | الصور فقط، في خانات ثابتة: center / left+right / ثلاثي |
| حزام الخريطة | 1000–1450 | كل نقطة تركيز ودبوس واسم مكان |
| واجهة يوتيوب السفلية | 1480–1920 | خريطة فقط، بدون عناصر |
- يمين الشاشة (x > 930) محجوز لأزرار يوتيوب: أسماء الأماكن تنقلب تلقائيًا لليسار إذا لم تتسع.
- الصور لا تغطي النصوص أبدًا، والكلمة الكبيرة لا تلمس البطاقة.
- بطاقة واحدة أو اثنتان أو ثلاث فقط في اللحظة، بمقاسات موحدة (portrait / landscape / half / small).
- خط منقط رفيع يربط البطاقة بالمكان على الخريطة.

## 3.2 الأساليب الثلاثة المتاحة
- **A — خريطة داكنة بخطوط:** `src/shorts/enigma/Enigma.tsx`.
- **B — وثائقي سينمائي:** صور أرشيفية كبيرة + آلة إنجما متحركة + شريط تلغراف + أبواب. `EnigmaDoc.tsx` + `src/lib/doc.tsx`.
- **C — لوحة تحقيق ورقية:** لوحة فلين، صور مطبوعة، دبابيس، خيط أحمر لعلاقات حقيقية فقط، ملصقات آلة كاتبة، أختام تاريخ، خريطة حبر على ورق، إضاءة مكتب وبقعة ضوء. `EnigmaPaper.tsx` + `src/lib/paper.tsx`. مبني على `docs/paper-documentary-master-prompt.md`.

## 4. سير العمل
1. السكريبت → يُرسل ككتلة واحدة → تسجّله وترسل WAV.
2. `python3 tools/transcribe.py vo.wav > words.json` → توقيت كل كلمة.
3. المشاهد تُبنى على توقيتات الكلمات (لا تقدير).
4. صور أرشيفية من Wikimedia Commons عبر `tools/fetch_art.py` (يحفظ الرخص في credits.json).
5. `tools/sfx.sh` لتوليد المؤثرات. رندر: `npx remotion render <Comp> out/<name>.mp4` ثم `tools/master.sh` لضبط الصوت على -14 LUFS.
6. مراجعة فريمات مفتاحية قبل الرندر الكامل (الحواف، النصوص المقصوصة، أول فريم).
